Cek Server Catat Panda

Halaman ini hanya mengecek, tidak mengubah apa pun di spreadsheet.

Cara baca hasilnya:
• v2.0 = server sudah versi baru, tombol Ubah akan bekerja.
• versi lama / aksi tidak dikenal = Web App masih menjalankan kode lama. Di Apps Script: Deploy → Manage deployments → ikon pensil → Version: New version → Deploy.
• Kode rahasia ditolak = isi TOKEN di Code.gs belum sama dengan yang dipakai aplikasi.
